**install**

needs a vencord source checkout with `pnpm install` done

1. clone it: `git clone https://github.com/Vendicated/Vencord.git C:\Vencord`
2. `cd C:\Vencord` and `pnpm install`
3. run `installer\INSTALL.cmd` and give it that path

undo with `installer\UNINSTALL.cmd`

**settings**

- `spoofClientBuild` - old client build
- `spoofAgeStatus` - adult status

both need restart
